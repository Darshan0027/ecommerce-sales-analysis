# E-commerce Sales Analysis Dashboard | Power BI

## Project Overview

An interactive Power BI dashboard for analyzing e-commerce sales performance, customer behavior, product performance, and geographical sales distribution.

This project covers data preparation, data modeling, DAX calculations, and interactive dashboard development.

## Business Objectives

- Monitor overall sales and quantity sold.
- Compare current-year performance with the previous year.
- Analyze monthly sales trends.
- Identify top-performing customers and products.
- Explore geographical sales distribution.
- Support data-driven business decisions.

## Tools and Technologies

- **Power BI Desktop** — dashboard development and visualization
- **Power Query** — data cleaning and transformation
- **DAX** — measures, time intelligence, and conditional formatting
- **PowerPoint** — dashboard wireframing and background design

## Project Workflow

1. Import source datasets into Power BI.
2. Clean and standardize data using Power Query.
3. Validate data types, missing values, and sales calculations.
4. Build relationships between fact and dimension tables.
5. Create DAX measures for sales, quantity, customers, and previous-year performance.
6. Develop interactive visuals, KPI cards, slicers, and geographical analysis.
7. Validate the dashboard using filters and year-over-year comparisons.

## Key Metrics

- Total Sales
- Total Quantity
- Total Customers
- Average Unit Price
- Previous-Year Sales
- Year-over-Year Growth

## Repository Structure

- `Dashboard/` — Power BI report file
- `screenshots/` — dashboard screenshots
- `datasets and materials/` — source datasets and supporting files
- `documentation/` — technical documentation

## How to Use

1. Download the `.pbix` report from the Dashboard folder.
2. Open the file in Power BI Desktop.
3. Review the report pages and interact with the available filters.
